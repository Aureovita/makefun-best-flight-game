Kestrel Vale — Valley Flight School: an original low-poly WebGL flight game. Fly a cream-and-red prop plane through an eight-gate ring course over a seeded sunset vale, attempt a judged runway landing, or take free flight — with a stall and energy flight model, fuel and damage, a full instrument HUD and generated WebAudio. No build step and no dependencies: the game is plain files under game/, and main.ts hands it in by decoding the stored screenshots and building the dossier.

## Run it

```sh
node serve.ts --port 8931
```

Then open http://localhost:8931 in a browser.
